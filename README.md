## 專案簡介
本專案是一個基於 Google Apps Script (GAS) 的後端自動化工具，專門用於整合 **AppSheet** 與 **Google Gemini AI**。當用戶在 AppSheet 中上傳名片照片後，此腳本會自動觸發，利用 Gemini 2.5 Flash 模型進行精準的 OCR 辨識，並將提取的資訊（姓名、電話、郵件、地址、公司）自動填回 Google Sheets 中。

## 技術棧
- **開發語言**: Google Apps Script (JavaScript V8)
- **AI 模型**: Google Gemini 2.5 Flash (Generative Language API)
- **底層整合**: AppSheet, Google Drive API, Google Sheets API

## 安裝與設定說明

### 1. 設置 Google Apps Script
1. 將 `code.js` 與 `appsscript.json` 的內容複製到您的 GAS 專案中。
2. 在 GAS 專案設定中，新增以下 **指令碼屬性 (Script Properties)**：
   - `GOOGLE_SHEET_ID`: 目標 Google Sheet 的 ID。
   - `IMAGE_FOLDER_ID`: 存放 AppSheet 上傳圖片的 Google Drive 資料夾 ID。
   - `GEMINI_KEY`: 您的 Google AI (Gemini) API Key。

### 2. AppSheet 自動化設定
在 AppSheet 的 Automation 中建立一個工作：
- **Event**: 當資料列有異動或新增時觸發。
- **Step**: Call a Script。
- **Function**: `processBusinessCard`。
- **Inputs**:
  - `imageFileName`: 傳入圖片欄位的內容。
  - `rowNumber`: 傳入 `[_RowNumber]`。
